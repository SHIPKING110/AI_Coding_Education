# 阿里云 FC 沙箱执行器部署说明（给第一次用的你，一步一步来）
#
# 原理一句话：我们在阿里云放一个"代跑脚本的小函数"，工作台把 Skill 脚本发给它跑，
# 跑完把结果拿回来。脚本跑在阿里云沙箱里，跑坏了也不影响你的服务器。
# 需要你在阿里云做的只有 3 件事：建函数 → 设触发器拿 URL → 设 token。
# 费用：FC 按量计费，每月有免费额度，这种偶发试运行基本在免费额度内。

# ============ 步骤 1：开通（2 分钟） ============
# 1. 登录阿里云控制台 → 搜索"函数计算 FC" → 开通服务（需实名 + 余额 ≥ 0）。
# 2. 地域随便选，建议和你 ECS 同地域（如 华东1杭州），延迟最低。

# ============ 步骤 2：建函数（5 分钟，控制台粘贴法，推荐） ============
# 1. FC 控制台 → 函数列表 → 创建函数 → "从零开始创建"：
#    - 函数名称：skill-sandbox
#    - 运行环境：Python 3.10
#    - 实例类型：弹性实例（按量，最便宜）
#    - 内存：512MB，超时：60 秒（这两个够用了）
# 2. 代码页：把同目录 index.py 的全部内容粘贴进去，入口填 index.handler，部署。
# 3. 高级配置 → 环境变量 → 添加：
#      SANDBOX_TOKEN = <你自己编一串至少 16 位的随机字符>
#    （这串字符就是"暗号"，工作台和函数凭它相认，不要告诉别人。）

# ============ 步骤 3：拿触发器 URL + 配工作台（3 分钟） ============
# 1. 函数详情 → 触发器 → 创建触发器：
#    - 类型：HTTP 触发器
#    - 认证方式：anonymous（鉴权靠我们自己的 SANDBOX_TOKEN，不要选 function）
#    - 请求方法：POST（允许 GET 也行，工作台用 POST）
# 2. 创建后复制"公网访问地址"，形如：
#      https://xxxx.cn-hangzhou.fcapp.run
# 3. 回到 Agent 工作台 → Skill 页 → 沙箱配置区：
#    - 提供商选"阿里云函数计算"
#    - Endpoint 粘贴上面的公网地址
#    - Token 粘贴步骤 2 的 SANDBOX_TOKEN
#    - 点"测试连通"→ 显示"连通正常"即配通。
# 4. 之后点脚本 ▶ 就是阿里云在跑了。脚本要第三方库？
#    FC 控制台 → 层管理 → 创建 Python 依赖层（pip install 到层里），
#    函数绑定该层即可；常用库如 python-pptx、pillow 都可以这样装。

# ============ 方式 B：s 工具部署（可选，适合以后改代码频繁时） ============
# 1. 本机安装：npm i -g @serverless-devs/s
# 2. s config add -a default -kl <AccessKeyId> -ks <AccessKeySecret>
#    （AccessKey 在右上角头像 → AccessKey 管理里创建，
#     权限给 AliyunFCFullAccess 即可，用完可删除。）
# 3. 部署前：export SANDBOX_TOKEN=<你的暗号>
#    cd 到本目录，执行：s deploy
#    （s.yaml 已写好）部署完输出里有 url，配到工作台即可。
