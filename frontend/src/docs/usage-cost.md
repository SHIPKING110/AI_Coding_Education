# 用量与成本

## 定位

用量与成本模块（`/usage`）将全链路 AI 调用量化为可对账的账本，回答三个问题：**谁在用、花了多少、账单是否对得上**。入口仅管理员/教务可见，教师无平台账单视角。

## 数据来源

- 所有 LLM、Embedding、Rerank 调用经统一下游出口，调用完成后由 `usage_meter` **异步记账**（失败不阻断业务）
- 每次记账携带：模块、模型、厂商、输入/输出 token、条数、耗时、归属（平台/教师）、时间
- 价格由 `pricing` 按版本化价格表计算，账本同时保留原始 token 与计算成本

## 指标口径

| 维度 | 口径 |
| --- | --- |
| 厂商计费 | 以厂商账单为准的原始用量 |
| 平台估算 | 按价格表折算的金额，用于内部对账 |
| 平台/教师归属 | 平台级调用与教师触发的调用分开统计 |
| 定价状态 | 已定价 / 未定价（未定价单独提示，避免误差混入总额） |

## 价格表

- 价格表**版本化**：每条价格有模型、单位（每 1M token）、币种、生效时间
- 变更价格产生新版本并设定 `effective_from`，历史账本不受影响
- 同一模型可存在多个版本，按调用时间匹配当时生效的价格
- 未配置价格的模型记为「未定价」，在看板单独展示

## 预算告警

- 预算按周期（月）设置阈值，接近阈值预警、达到阈值强提醒
- 告警**幂等**：同一周期同一阈值只触发一次，避免重复骚扰
- 预算变更属于高影响操作，需二次确认并记录审计

## 月度对账

```text
差异 = 平台账单 - 账本成本
差异率 <= 2%   → 正常
2% ~ 5%        → 关注（排查未定价、漏记）
> 5%           → 异常（需核对厂商用量与价格版本）
```

对账页展示当月差异、未定价调用与 Top 消耗模块，支持导出明细。

## 成本归因（模块）

| 模块 | 说明 |
| --- | --- |
| `agent` | Agent 对话与工具调用 |
| `report` | 日报/周报/总结生成 |
| `evaluation` | 学员评估生成 |
| `assignment` | AI 习题生成与批改 |
| `parent_service` | 家长教学服务 |
| `embedding` / `rerank` | 检索向量化与重排 |
| `config_test` | 模型/配置连通性测试 |
| `rag_eval` | RAG 评测（生成回答与裁判打分） |

> 归因依赖 `llm_context` 注入的模块与对象信息；新增 AI 场景时务必补充上下文，否则会落入未知模块。

## 数据保留与汇总

- 明细账本按保留策略滚动清理
- 月度汇总**永久保留**，作为长期对账依据
- 导出与预算变更分别受 `usage_view` / `usage_price_create` / `usage_budget_save` / `usage_recon_upsert` 权限控制

## 使用建议

1. 每月初核对上月差异，先处理「未定价」再判断差异
2. 关注 Top 模块占比，异常增长优先排查 `agent`、`rag_eval`
3. 价格变更走版本化流程，不要直接改历史记录
4. 预算阈值结合历史用量设定，避免过低频繁告警
