# 上线冒烟测试清单（SMOKE CHECKLIST）

目标：生产环境（或本地生产 compose）首次部署后，45 分钟内验证主链路可用。
约定：P0 必须全过才能上线；P1 建议上线前过；P2 上线后一周内补。

说明：`[ ]` 待测，`[x]` 通过，`[!]` 不通过（记编号到文末缺陷表）。

## A. 部署与登录（P0，5 分钟）

- [ ] `docker compose --env-file .env.prod up -d --build` 三容器 Up，db 为 healthy
- [ ] 后端日志 `Application startup complete`，无 Traceback
- [ ] 打开 `http://服务器IP:端口` 显示登录页（标题“智能少儿编程教育”）
- [ ] `seed_admin` 建管理员并登录成功
- [ ] 登录后改掉初始弱密码
- [ ] 左侧菜单完整：学员管理、招生邀约、班级管理、教师管理、排课与考勤、课时包管理、财务管理等

## B. 招生邀约链路（P0，10 分钟）

- [ ] 新建邀约：家长姓名/电话/学员/科目/备注/聊天截图上传成功，列表出现该记录
- [ ] 编辑邀约：改电话/备注保存生效
- [ ] 筛选联动：选校区后邀约人/体验教师收窄；选科目后体验教师收窄
- [ ] 建体验学员档案 → 状态推进到“已排体验课”（排体验课：选班级+教师+时间，结束时间自动+90 分钟）
- [ ] 冲突校验：同班同时段再排一节被拦截并提示冲突
- [ ] 标记已到场 → 报名成功（标口碑/介绍人）→ 学员管理中该学员变为正式
- [ ] 反向用例：另一条邀约标记“未报名结束” → 体验学员档案自动从学员管理消失，邀约为 lost

## C. 排课与考勤（P0，10 分钟）

- [ ] 新建单次排课成功；课表按周展示正确（时间/班级/教师）
- [ ] 体验课卡片带“体验课”标签
- [ ] 考勤：正式学员“已到”扣课时（默认 2，乐高 1.5），余额减少，收支流水+1 条扣减
- [ ] 体验学员“已到”不扣课时不计创收，只记到场
- [ ] 余额不足 + 透支上限为 0 时被拦截并提示“不足”；透支上限 10 时允许欠费上课
- [ ] 未到上课时间的课点考勤被拦（“未到上课时间”）
- [ ] 已标记考勤不可重复改（提示不能重复操作）
- [ ] 请假不扣课时

## D. 财务与薪资（P0，10 分钟）

- [ ] 财务管理三个 Tab（订单/课时创收/收支流水）+ 薪资核算 Tab 数据正常展示
- [ ] 充值入账：学员余额增加，流水+1 条
- [ ] 薪资核算 Tab：进入自动核算出数字；点某人“查看明细”每项可溯源到具体名单
- [ ] 确认锁定后，刷新重算不再覆盖；重新自动核算可解锁重算
- [ ] 权限：教师账号看不到财务管理（未授权时菜单隐藏）

## E. 权限与通知（P1，5 分钟）

- [ ] 权限管理新增职务预设并关联教师，教师端菜单按导航开关显隐
- [ ] 排体验课后，体验教师收到站内通知（含班级+时间）
- [ ] 教师只能看/操作与自己相关的邀约与排课

## F. 运维基线（P0，5 分钟）

- [ ] `docker compose restart backend` 后服务恢复，数据不丢
- [ ] 数据库备份命令可执行且恢复演练通过（测试库恢复一次）
- [ ] uploads 卷备份命令可执行
- [ ] 磁盘/内存余量：`df -h`、`docker stats` 无持续 90%+

## 后续测试计划（上线后）

1. **全量自动化回归**（每次发版前）：`pytest tests`（约 9 分钟）+ `ruff` + `npm run build`，发版 checklist 门禁。
2. **备份恢复演练**（每月一次）：用备份在测试环境恢复，确认 RPO/RTO 可接受。
3. **性能摸底**（P2）：课表周视图 200+ 排课、学员 1000+ 时列表/考勤响应；慢接口加索引或分页。
4. **安全基线**（P2）：SECRET_KEY 已换强随机；管理后台不对公网裸奔（建议 IP 白名单/VPN）；上传文件类型与大小限制已生效（20MB/图片）。
5. **UAT（上线第一周）**：找 1 名教务真实录一周数据，收集反馈修一轮。
6. **微信推送**：拿到商户资质后按 OQ-01 预留接口接入，单独提 PR + 回归。
