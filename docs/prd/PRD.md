## 1. 产品概述

### 1.1 背景与痛点

少儿编程培训机构的教师日常工作存在大量重复性、繁琐的事务性工作：

- 每节课后需为每位学生撰写课后反馈并单独发送给家长，学生多时工作量巨大；
- 需周期性产出日报、周报、月度总结、季度总结、年度总结；
- 每 3 个月一次家长会，需为每个孩子撰写综合评估表并制作 PPT，人工编写极其耗时；
- 学员信息、课时消耗、排课、考勤、催缴等管理依赖人工记录，易出错、难统计。

### 1.2 产品目标

1. **提升教师效率**：借助 AI 自动生成课后反馈初稿、周期报告、学员评估表与 PPT 模板，教师仅需审核、修改、确认，显著压缩重复劳动时间；
2. **提升家长粘性**：家长/学员可通过客户端实时查看课时余量、课后反馈、作业并完成续费订阅，形成机构与家庭的高频互动；
3. **管理数字化**：学员、班级、课时包、排课、考勤、催缴名单全流程在线管理，数据可统计、可追溯。

### 1.3 成功指标（建议）

| 指标 | 目标 |
| --- | --- |
| 教师课后反馈撰写耗时 | 单生单次 ≤ 5 分钟（AI 草稿 + 人工微调） |
| 周报/季度/年度总结生成耗时 | 模板生成 ≤ 3 分钟，审核修改 ≤ 30 分钟 |
| 学员评估表生成耗时 | 单生 ≤ 10 分钟（基于 3 个月课后反馈自动总结） |
| 家长月度活跃度 | 客户端月活 / 在读学员数 ≥ 60% |
| 课时续费线上化率 | 订阅课时占总续费 ≥ 50%（后期真实支付接入后） |

### 1.4 产品范围（In Scope / Out of Scope）

**In Scope（本 PRD 覆盖）**

- 教师端：课后反馈、日报、周报、季度/年度总结、学员评估、学员管理、排课、划课时、AI 习题生成与作业发布
- 客户端（家长/学员）：课时查询、反馈查看、课时订阅、提醒通知、在线作业作答
- 管理端：课时包发布、催缴名单、基础数据维护
- AI 能力：文本生成（反馈/报告/评估）、PPT 模板生成、习题生成

**Out of Scope（本期不做 / 后续迭代）**

- 真实支付渠道对接（本期以模拟支付 + 管理员确认到账，预留支付接口）
- 财务对账、发票、退款等完整财务能力
- 教师课酬结算、薪酬体系
- 教学直播/录播、在线课堂
- 多校区/多机构多租户
- 短信通道（预留渠道位，暂不实现）

## 3. 功能需求

> 优先级定义：**P0** = 首版必须；**P1** = 首版应有（可二期）；**P2** = 增强体验/可延后。

### 3.1 课后反馈（教师端）

| 编号 | 需求项 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FR-FB-01 | 反馈创建 | 每节课程结束后，教师为该班学员逐一生成课后反馈 | P0 |
| FR-FB-02 | 反馈字段 | 包含：课题、课程大致内容、课堂表现、今日作业、学生上课照片/视频 | P0 |
| FR-FB-03 | AI 草稿 | 教师可调用 AI 根据课堂记录/课程信息生成反馈草稿，人工编辑后发送 | P1 |
| FR-FB-04 | 素材上传 | 支持上传上课照片/视频，作为反馈附件 | P0 |
| FR-FB-05 | 发送给家长 | 反馈保存后推送至对应家长客户端（应用内 + 微信通知） | P0 |

- 照片/视频大小与格式需在系统设计中约定（如 ≤ 20MB，jpg/png/mp4）。

### 3.7 学员管理（教务端）

| 编号 | 需求项 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FR-ST-01 | 学员增删改查 | 添加、删除、修改、查询学员信息 | P0 |
| FR-ST-02 | 学员分班 | 学员可被分配到一个或多个班级，班级绑定科目/教师 | P0 |
| FR-ST-03 | 信息标签 | 姓名、联系电话、班级、带教教师、所学科目、课时数 | P0 |
| FR-ST-04 | 课时状态标记 | 课时数低于 10 节时状态"爆红"，自动进入催缴名单 | P0 |
| FR-ST-05 | 催缴名单 | 教务可查看催缴名单（低于 10 节的学员）并跟进催缴 | P0 |

**业务规则**
- 每上一节课扣 2 课时（见 3.9/3.10）；
- 课时数 ≤ 10 节（即"低于 10 节"）时触发爆红提醒与催缴名单收录；课时数 ≤ 0 时禁止正常上课扣减（可请假或提示续费）；
- 删除学员需二次确认，历史数据（反馈/作业/考勤）归档保留。

### 3.8 课时包发布（管理端）

| 编号 | 需求项 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FR-PK-01 | 课时包编辑 | 高权限管理员编辑课时包：价格、总课时、课时包封面图 | P0 |
| FR-PK-02 | 发布/下架 | 课时包发布后在客户端可见可购买，下架后不可再购买 | P0 |
| FR-PK-03 | 版本管理 | 课时包内容变更保留历史版本记录 | P2 |

**业务规则**
- 课时包为"购买单位"，学员购课后按课时入账（如 40 课时包 → 学员课时 +40）；
- 学员购买多个课时包时课时累加，不区分来源（可迭代为按包核销）。

### 3.9 学员课程安排 / 排课（教师端 + 教务端）

| 编号 | 需求项 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FR-SC-01 | 班级排课 | 教师依据班级进行排课，维护个人排课时间表 | P0 |
| FR-SC-02 | 课时规则 | 一次上课 90 分钟，扣 2 课时 | P0 |
| FR-SC-03 | 冲突检测 | 排课时间与其他班级/自身时间段冲突或重叠时提醒 | P0 |
| FR-SC-04 | 冲突详情 | 提醒给出冲突班级与时间段，由教师决定是否替换（新排班级覆盖原安排） | P0 |
| FR-SC-05 | 排课时间表 | 教师可查看本人周排课时间表（日历视图） | P0 |

**业务规则（冲突检测算法）**
- 冲突判定：同一教师在不同班级的排课时间区间发生重叠（`start < new_end AND new_start < end`）即视为冲突；
- 允许的替换：教师确认后，新排课替换/覆盖冲突时间段的旧排课，替换需记录操作日志；
- 同一班级同一时间段内一次课对应一条排课记录；排课状态（未开始/进行中/已结束/已取消）需可追踪。

### 3.10 划课时 / 考勤（教师端）

| 编号 | 需求项 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FR-AT-01 | 到课操作 | 排课班级到上课时间后，教师进入该班级分组，对已入班学员点击"已到"或"请假" | P0 |
| FR-AT-02 | 已到扣课时 | 点击"已到"自动扣除该学员 2 课时 | P0 |
| FR-AT-03 | 请假不扣 | 点击"请假"不扣课时 | P0 |
| FR-AT-04 | 防重复扣减 | 同一学员在同一堂课时间段已点击"已到"后，按钮置灰不可再扣 | P0 |
| FR-AT-05 | 未标记处理 | 课后未标记学员默认状态可配置（如默认"未到"不扣课时，需人工确认） | P1 |

**业务规则**
- 扣课时为不可逆事务操作：`课时数 = 课时数 - 2`，需记录扣减流水（学员、班级、排课、时间、操作人）；
- "已到"按钮置灰判定：以排课记录维度校验该学员是否存在已扣课时流水；
- 若学员课时不足（< 2），点击"已到"时给出提示并阻止扣减，允许标记"请假"。

### 3.11 AI 生成习题（教师端）

#### 3.11.1 举一反三模式

| 编号 | 需求项 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FR-AI-01 | 参数输入 | 教师输入题目、返回题数、难度（1-5 级）、提示语（可选） | P0 |
| FR-AI-02 | 题目生成 | 点击"确认"后在题目模板窗口生成题目 | P0 |
| FR-AI-03 | 答案折叠 | 答案与解析不直接显示，位于对应题目下方的下拉框中，默认收起 | P0 |

#### 3.11.2 作业模式

| 编号 | 需求项 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FR-AI-04 | 参数输入 | 输入题数、提示语（知识点），点击确认生成 | P0 |
| FR-AI-05 | 对话优化 | 可在对话窗口通过对话对题目进行修改优化 | P0 |
| FR-AI-06 | 模板窗口编辑 | 可在题目模板窗口实时更改题目并保存 | P0 |
| FR-AI-07 | 每题一页 | 题目逐题展示，每题一页，附带收缩栏答案解析 | P0 |
| FR-AI-08 | 题号选择 | 收缩栏提供选择题号按钮（1、2、3...）快速定位 | P0 |
| FR-AI-09 | 题型设置 | 选择题（单选/多选）、判断题（√/×）、代码填空题（输入框）、编程题（Python/C++ 代码编写） | P0 |
| FR-AI-10 | 作业保存 | 修改好后保存作业 | P0 |
| FR-AI-11 | 作业发布 | 选择对应班级发布，对应班级学员客户端可接收查看 | P0 |
| FR-AI-12 | 完成时间设置 | 发布作业可设置完成时间（可选）；超时未完成判定"未提交"，客户端不可再操作 | P0 |
| FR-AI-13 | 文档下载 | 作业可选择保存为文档下载到本地，按题目顺序逐行写入（非一题一页） | P1 |

**业务规则**
- 题型枚举：`single_choice`（单选）、`multiple_choice`（多选）、`judgement`（判断）、`code_fill`（代码填空）、`programming`（编程题）；
- 难度枚举：1-5 整数；
- 作业状态机：`草稿 → 已发布（待作答） → 进行中（部分提交） → 已截止/已提交 → 已批改`；
- 截止时间判定以服务器时间为准；截止后作答界面锁定，状态标记"未提交"。

### 3.14 客户端 - 在线作业作答

| 编号 | 需求项 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FR-CL-09 | 作业列表 | 学员查看已发布给本班、未过截止时间的作业 | P0 |
| FR-CL-10 | 顺序作答 | 学员按题目顺序作答（选择题单选/多选、判断题、代码填空、编程题） | P0 |
| FR-CL-11 | 跳题作答 | 通过题号按钮选择做任意一题 | P0 |
| FR-CL-12 | 自动保存 | 选择/填写过的题目点击下一题自动保存答案 | P0 |
| FR-CL-13 | 手动保存 | 未做完时提供保存按钮，下次继续上次进度 | P0 |
| FR-CL-14 | 题号状态色 | 已做题号按钮显示绿色，未做题号按钮区分显示 | P0 |

**业务规则**
- 作答进度以学员维度持久化（作业 × 学员），支持断点续做；

- 编程题作答：提供 Python/C++ 代码编辑器（输入框 + 基础语法高亮）。

## 6. 技术栈与架构约束

| 层级 | 技术选型 | 说明 |
| --- | --- | --- |
| 前端 | Vue 3（+ Vite + TypeScript） | 管理端与客户端 H5 |
| 后端 | Python（FastAPI） | RESTful API + WebSocket（AI 异步推送） |
| AI 编排 | LangChain / LangGraph | Agent 工作流：反馈/报告/评估/PPT/习题生成 |
| Prompt/Skill | prompt + skill | 结构化提示词与可扩展 skill 工具（`.claude/skill/`） |
| 向量库 | ChromaDB | 知识检索（课程资料、历史反馈、题目库 RAG） |
| 数据库 | PostgreSQL | 业务数据主库 |
| 模型 | deepseek-v4-pro（可配置） | 默认模型，支持自定义配置（PPT 生成需要） |
| PPT 生成 | python-pptx | 季度/年度总结与家长会 PPT |
| 虚拟环境 | uv | 依赖安装需科学上网，提供依赖文件与安装命令 |
| 文档规范 | `.claude/rules/*.mdc` + `spec/*.md` | 治理与设计约束 |

**架构约束**
- 前后端分离，API 统一 `/api` 前缀；
- AI 能力全部通过后端 LangChain/LangGraph 服务暴露，前端不直接调用模型；
- 所有"生成类"功能产物必须有状态流转（草稿/审核/发布），不允许 AI 结果直发家长端；
- 文件存储本地目录（可配置），PPT/文档导出产物存档。

## 9. 验收标准（要点）

- [ ] 教师可对任意学员完成"反馈生成 → 审核 → 发送"全流程，家长端实时可见；
- [ ] 周报统计指标（上课人次/出勤率/缺课人次/缺课学员/新增学员）与考勤、学员数据一致；
- [x] 季度/年度总结可一键生成 PPT 草稿、在线修改、保存导出；
- [ ] 学员评估表可基于 3 个月反馈自动生成，支持教师对话式优化与确认；
- [ ] 排课冲突检测准确提示冲突班级与时间段，教师可确认替换；
- [ ] 划课时"已到"扣 2 课时且同排课不可重复扣减，"请假"不扣；
- [ ] 课时 ≤ 10 节自动爆红并进入催缴名单；
- [ ] AI 习题两种模式均可用，答案/解析默认折叠；作业发布后客户端可作答，截止后标记"未提交"；
- [ ] 客户端作业支持跳题、自动/手动保存、空题跳转最小题号、全部完成才可提交；
- [ ] 课时订阅订单（模拟支付）经管理员确认后课时自动入账；
- [ ] 上课前一天与课时低余量提醒正常推送（应用内 + 微信）。
