# ADR-0026：人工复核只打 correctness + 关键词命中度量增强与生成口径收敛

- 状态：已采纳
- 日期：2026-11-13
- 关联：ADR-0022、ADR-0024、`backend/app/services/rag_evaluation.py`、`frontend/src/views/rag/EvalResultReviewDialog.vue`

## 背景（Context）

基线运行 `f775fd92`（hybrid · 家长索引，answer_eval=on，51 条全量人工复核）出现三个问题：

1. **Kappa 0.4564 低于门槛 0.6**。配对矩阵显示双方均分几乎一致（LLM 4.08 / 人工 4.12，bias −0.04），分歧不来自系统性偏移，而是打分口径不一致：
   - 人工按「五维综合印象」打分（完整性不足扣分、招呼语/不可答正确拒答给 5）；裁判 `correctness` 的定义是「与标准答案事实是否一致」；
   - 4 条极端分歧（裁判 0-2 vs 人工 5）全部来自拒答场景：人工按业务规则给 5，裁判给 0-1；
   - 14 条 `5 vs 3/4` 分歧来自人工把「回答简陋」扣到了 correctness 上——那是 completeness 维度的事。
2. **复核指标不可见（实现 bug）**：`recompute_run_calibration()` 对已加载的 `run.metrics`（普通 JSON 列）做原地修改，SQLAlchemy 变更追踪捕获不到，`commit()` 空写——无论复核多少条，Kappa/闸门重算都落不了库。已修复为整体赋值 `run.metrics = metrics`。
3. **关键词命中 66% 被高估的短板与低估的误导并存**：
   - 41 条带关键词的可答用例中，平均命中 65.7%；剔除 5 条拒答（0 命中）后为 74.8%；
   - 匹配器是不分词连续子串：`7级（≥80分）` 不匹配标注 `7级80分`、`免CSP-J第一轮` 不匹配 `免第一轮`、`三个工作日` 不匹配 `3个工作日`——度量偏严产生假阴性；
   - 生成 prompt「片段没有直接依据必须只输出文档未提供」过于激进，综述类问题（课程清单、几岁开始）被直接拒答。

## 决策（Decision）

### 1. 人工复核口径：只打 correctness（与闸门实现对齐）

- 复核打分仅评估 `correctness`（事实正确性）：与标准答案一致=5；用例不可答且正确拒答=5；编造/事实错误=0-2；部分一致=3-4；
- 完整性、表达等感受写入「理由」，不体现在分数上；复核弹窗展示该 rubric 提示；
- 裁判 prompt 本轮**不动**（避免评测口径与历史基线不可比）；抽样协议仍按 ADR-0022（分层 12 条起步，全量复核亦有效）；
- **基线上 51 条需按新 rubric 覆盖重评**，保存即触发 Kappa 重算（持久化 bug 已修复）。

### 2. 关键词命中度量增强

- `_normalize_match` 增加中文数字→阿拉伯数字归一（0-99，含「十二」「二十」）与比较符号（≥≤≈± 等）剔除；
- 命中判定新增「ASCII 插入」子序列回退：允许关键词字符间插入 ASCII 字母/数字片段（如「免CSP-J第一轮」命中「免第一轮」），间隔含中文则不算命中，防止跨句拼接虚高；
- 新增指标 `keyword_hit_non_abstained`（剔除拒答后的命中率），面板在「答案关键词命中（可答）」旁并列展示，拒答行为继续由「不可答拒答率」单独衡量；
- 关键词标注治理指引：`gt_keywords` 使用最小核心词（`7级80分` 应拆为 `7级` + `80分`），避免整句短语与含符号词。

### 3. 生成口径收敛（拒答条件）

- 生成 prompt 改为：先通读全部片段并逐条提取；列出多项内容时必须完整列出；仅当全部片段都与问题无关时才输出「文档未提供」；
- 该改动改变生成行为与可答边界：**属于评测口径变更，旧基线作废**，需重跑基线并重新复核。

## 后果（Consequences）

- 修正 rubric 后 51 条重评，Kappa 有望显著提升；注意 5 分档高度集中导致期望一致度 pe 很高，仅修极端拒答分歧不足以过 0.6，`5 vs 3/4` 的口径差必须一并消除。
- 关键词指标前后不可比：新匹配器与生成 prompt 同时生效后，需以新基线为起点；检索类指标（hit@k/MRR/recall）不受影响。
- 复核 Kappa、闸门重算现在能正确落库；任何未来对 `run.metrics` 的修改必须整体赋值（禁止原地改 JSON 列），否则重演「指标永远不更新」。
- 发版闸门口径不变（ADR-0022）：answer_eval=on、人工 ≥10 对且 Kappa ≥0.6、存在基线、冻结/关键切片无 >2pp 回退。
