# ADR-0012：Agent 联网搜索（Tavily）的边界与驱动方式

- 状态：已采纳
- 日期：2026-10-22
- 关联：ADR-0001/0002/0003/0004、app/services/agent_tools.py、app/services/agent_planner.py、app/services/web_search.py

## 背景（Context）

智能助手目前只能看到两类事实：**系统内部业务数据**（排课/考勤/课时/班级/学员/评估，经只读工具取数）
与**知识库片段**（教师上传的制度文档，经 RAG 检索）。二者都回答不了"外部公开信息"类问题：
行业最新动态、同行（竞品）的收费与课程做法、公开政策/标准原文、通用技术资料。

同时本系统是**教务系统**：学员名单、课时余额、收费与退费标准、请假制度都是机构内部事实。
若把公网搜索结果与内部数据混在一个上下文里让模型自由取用，最坏情况是：
模型用网上某家机构的"少儿编程收费 120 元/课时"去回答本校关于**本校收费**的提问。

因此接入联网搜索的前提不是"能不能搜"，而是**内外事实如何分层、谁能被谁覆盖**。

## 决策（Decision）

### 1. 定位：外部事实补充，不参与内部事实裁决

- 联网结果只补充**外部公开事实**（行业动态、竞品做法、公开资料、通用知识、最新公开政策）。
- **本校的学员/课时/排课/收费/退费/请假政策，一律以内部业务数据与知识库为准**。
- 冲突时**内部数据与知识库优先**；两者都没有则如实说明"系统内没有查到"，不拿公网内容充数。

### 2. 驱动方式：规划器的一个普通工具（模型自主决定）

不新建平行链路，而是把 `web_search` 注册为规划层工具之一，与既有 14 个只读工具同构：

- 复用现有 **规划 → 执行 → 观察** 多轮 function-calling 循环（`agent_planner.plan_and_run`）、
  `TOOLS_SCHEMA` 工具声明、工具轨迹（`tool_trace`）与降级护栏。
- **是否联网由模型判断**，不写死关键词路由；代码侧只做"放行门控"：
  `looks_like_web_search()` 命中"最新/近期/政策/竞品/搜一下/了解一下…"等外部/时效信号时，
  允许规划器参与（否则这类问题会被业务门控直接跳过，模型根本没机会调用搜索）。
  真正的检索决策仍由模型依据工具描述做出。
- 工具描述里写明"若内部数据或知识库已能回答，就不要调用本工具"，抑制无谓调用与 credit 消耗。

### 3. 内外分块注入：两个独立区块，不混排

`agent_planner._format_block()` 改为按来源分块：

- 【业务数据】（系统实时数据，请据此作答并注明数据周期）
- 【联网搜索结果·公网外部资料】（仅用于补充外部事实，**不得**用于回答本校内部问题；
  引用时标注来源链接；与内部冲突一律以内部为准）

助手系统提示词（`agent_chat.build_unified_prompt`）同步补一条硬约束，明确"绝不能用联网结果回答本校内部问题"。

### 4. 配置：系统级单例（管理员），与 Embedding 同款范式

- 新表 `system_search_config`（单例），`api_key_enc` 经 secretbox 加密存储，对外只出掩码。
- 管理员在**设置 → 模型配置 → 联网搜索 · Tavily（系统级）**配置 Key、搜索深度、每次条数、语言偏好，
  并可做连通性检查。
- **未配置 / 停用 → 工具返回明确提示**（"联网搜索未启用…本次只能依据系统内部数据与知识库作答"），
  不抛异常、不影响内部数据与知识库问答——这是"可选增强"的语义。

### 5. 降级与限额

- 搜索在规划器的工作线程内同步执行（`httpx`，20s 超时）；超时、401、429、余额不足等
  一律转成可读中文错误，**不打断对话**。
- 单次返回条数上限（默认 5，硬上限 20），摘要按条截断（500 字符），
  最终再由 `compact_result` 按整条裁剪——回灌给模型的体积可控。

## 理由（Rationale）

- **同构扩展**：复用规划层而非另起链路，新增工具的成本与既有工具一致，
  工具轨迹、降级、超时、预算护栏全部自然继承。
- **边界优先于能力**：教务系统的错误信息代价高（错误收费口径、错误政策），
  所以"公网不得裁决内部事实"是硬约束，写在工具描述、注入块、系统提示词三处。
- **可选增强**：未配置时零影响，避免"为了联网而联网"的架构复杂度。

## 后果（Consequences）

- 正向：助手可回答外部事实类问题；内外事实分层清晰；配置一处全校可用。
- 代价：
  - 公网内容**不可信**（可能含误导/注入），已用"仅作外部事实 + 不得裁决内部 + 冲突以内部为准"三重约束降低风险，
    但不能完全消除——后续若要更高安全性，需引入内容白名单/来源可信度分级。
  - Tavily 按 credit 计费（basic 1 credit/次，advanced 2 credits/次），
    搜索深度与条数在配置侧可调，生产上建议保持 basic。
  - 工具轨迹里会出现 `web_search` 一行（含 query 与结果摘要），前端"执行链路"可展开查看来源链接。
