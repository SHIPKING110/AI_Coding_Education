# ADR-0011：知识库模型——Document / KnowledgeBase / Plaza / Collection

日期：2026-09-21
状态：已接受

## 背景

知识库要支持：上传文件；私有库（仅本账号可引用）与公用库（上传到「广场」，需填标题与描述）；
其他教师可「收录」广场文档后引用。需要一套明确的术语与数据关系，避免「收藏/订阅/共享」等含糊说法。

## 决策

- **Document（文档）**：上传与入库单位，含标题、描述、文件、所有者、可见性。
- **KnowledgeBase（知识库）**：Document 的逻辑集合，范围 = 私有库（Private）或广场（Plaza）。
- **Plaza（广场）**：公开可发现的公共区域；上传需填标题 + 描述以保证工整。
- **Collection（收录）**：用户对广场 Document 的**引用**（不复制向量）；收录后才可被该用户引用。
- **引用范围**：检索 = 本人私有库 + 本人已收录的广场文档；广场未收录文档不参与检索。
- **物理存储**：单一 Chroma collection + metadata 过滤（非每库一个 collection）。

## 否决的备选

- 收录 = 复制向量：广场文档更新/下架后副本失效或不同步，且浪费空间，否决。
- 每 KB 一个 collection：跨库检索与权限过滤复杂，否决。

## 后果

- 新增 `document`、`collection`（用户↔文档关联）等表；`visibility` 决定是否进广场。
- 作者下架广场文档 → 所有收录失效；文档更新 → 对所有收录者即时生效。
- 检索时按 `owner_id + 已收录 doc_id` 过滤 Chroma 结果。
